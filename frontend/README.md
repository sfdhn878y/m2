Code	Meaning
200	Request successful
201	Resource created successfully
400	Bad request
401	Authentication required
403	Access forbidden
404	Resource or URL not found
405	HTTP method not allowed
500	Internal server error

Remember:
- 404 → Requested route or resource not found.
- 405 → Route exists, but the HTTP method (GET/POST) isn't allowed.
- 500 → Something went wrong while executing the backend code.
